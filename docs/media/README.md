# Product demo media

- `alias-gmail-demo.mp4`: 27-second, 1280×720, silent H.264 demo.
- `gmail-compose.png`: composing a message with the recipient masked.

Captured September 6, 2026 from the original Alias release. This is an edited sequence of real Gmail UI captures with added zooms, cursor emphasis, captions and shortened timing. It is not a continuous screen recording, and it is not a new end-to-end test of the standalone source edition.

The public business sender is shown intentionally. Recipient identity is masked; inbox background, credentials and browser account controls are excluded. Private raw captures are not included.

The former website appears at the end of the video. The store listing and managed service are discontinued; follow this repository's README for local installation. The demonstrated route requires your own verified domain and Resend account. Provider limits and charges apply.
